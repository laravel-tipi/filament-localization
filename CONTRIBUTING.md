# Contributing

Thank you for contributing to Laravel Tipi Filament Localization.

## Development

Install dependencies:

```bash
composer install
```

Run the complete package check:

```bash
composer check
```

Format the code when needed:

```bash
composer format
```

Please include tests for behavior changes and keep changes focused on the Filament integration. Locale domain behavior belongs in `laravel-tipi/localization`.
